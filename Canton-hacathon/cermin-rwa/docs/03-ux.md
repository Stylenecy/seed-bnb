# 03 — UX Specification (Neobank style)

## Design principles

1. **Calm, not casino.** No red flashing numbers, no charts screaming. Feels like Revolut/N26 private banking, not a DEX.
2. **One number rules the screen: Health Ratio**, rendered as a serene ring/dial. Green zone = "Protected". The user should feel safe by glancing.
3. **Protection is a story, not a log.** Every agent action becomes a human sentence in an activity feed: "Gold dipped 4%. I repaid $1,200 from your Shadow Vault. Your position is safe. — Cermin"
4. **Privacy made visible.** Small "Only you can see this" badges on vault balance and positions. Privacy is the selling point; the UI must keep saying it quietly.

## Screens (5 total — no more)

### 1. Onboarding (60 seconds)
Three slides: "Post your assets" → "Fund your Shadow Vault" → "Sleep well". Then connect party/wallet. No forms beyond what LocalNet needs.

### 2. Home / Dashboard
- Hero: Health Ratio ring + status word ("Protected" / "Guarded" / "Action suggested").
- Cards: Collateral (mUST balance, current value, next coupon date), Loan (outstanding, rate), Shadow Vault (balance + privacy badge).
- Cermin activity feed (the story stream).

### 3. Borrow flow
Pick collateral amount → slider for loan amount with live Health Ratio preview → set Guard Trigger (sane default 130%, "recommended" chip) → toggle Coupon Sweep → confirm. Max 3 steps, always show "what happens if price drops 10%?" preview line.

### 4. Shadow Vault
Balance (privacy badge), top-up / withdraw, and "protection runway": *"Your vault can absorb a 23% price drop."* — the single most reassuring sentence in the product.

### 5. Simulation mode (demo weapon)
A dev-only panel (styled as a "market simulator") with a price slider. Judges watch: price slides down → ring dips toward amber → agent fires → feed prints the rescue sentence → ring returns to green. This 20-second moment IS the demo.

## Copy tone

First person from Cermin, short sentences, zero jargon. Say "repaid" not "deleveraged". Say "your money only you can see" not "selective disclosure". Indonesian-English glossary kept for pitch; product copy in English.

## Anti-goals

No dark-mode-neon-degen theme, no token tickers everywhere, no TVL vanity metrics, no confetti (one subtle checkmark animation max).
